# Runtime dependencies. Pinned exactly: this pipeline runs once over an
# irreplaceable archive, so a silent upstream change in a decoder or a
# metadata writer is a correctness risk, not a convenience one.
#
# Every pin below publishes a cp314 wheel for win_amd64, manylinux x86_64 and
# macOS arm64 (verified 2026-08-28, when CI grew a three-platform matrix for
# tiers 1 and 2). Windows is still the only platform the desktop app ships
# for and the only one tiers 3 and 4 have ever run on.
# ExifTool is NOT a Python package -- see the README and docs/GUIDE.md for
# how it is installed.

# Nothing here may be copyleft: these are the packages PyInstaller bundles
# into the published Windows executable, and the project ships Apache-2.0.
# `pyexiv2` used to live here and is now dev-only -- see requirements-dev.txt.

olefile==0.47
numpy==2.5.2
pillow==12.3.0
# Pillow's `Image.getxmp()` parses the XMP packet through defusedxml and
# returns an empty dict without it -- which would turn the validator's XMP
# checks into checks that cannot fail. It is a hard runtime requirement of
# the read-back validator, not an optional extra.
defusedxml==0.7.1
# Windows ships no IANA time zone database, so `zoneinfo` finds nothing
# without this pure-Python data-only wheel. Time zones decide the
# `OffsetTime*` written beside every timestamp, and 1998-2002 dates need the
# historical DST rules rather than today's.
tzdata==2026.3
